# Burp Suite Security Testing Project

## Overview
This repository contains my Burp Suite web application security testing practice and learning documentation.

## Tools Used
- Burp Suite Community Edition
- Kali Linux
- Web browser (Firefox/Chrome)

## Project Structure
- reports/ → Vulnerability reports
- screenshots/ → Captured test results
- notes/ → Learning notes

## Purpose
This project is for learning web application security testing, identifying vulnerabilities, and improving penetration testing skills.
